# Changelog

All notable changes to this package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.0.1] - 2026-07-06

### Added
- Initial release of MM Attributes package.
- Over 25 custom attributes for grouping, validation, conditionals, drawers, and buttons.
- Custom inspector drawing engine for rendering box groups, foldouts, reorderable lists, progress bars, and more.
- Added `[ShowIfEnum]` and `[HideLabel]` attributes.
